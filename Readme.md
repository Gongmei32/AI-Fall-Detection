# AI Fall Detection System

A real-time computer vision project for detecting human falls using deep learning and pose estimation.

## Features
- Real-time webcam detection
- Pose estimation
- Fall detection
- Event logging
- Multi-person support
- Research-ready architecture

## Tech Stack
- Python
- OpenCV
- MediaPipe
- YOLO
- PyTorch
